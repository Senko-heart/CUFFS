# Changelog

## 1.01 - 2026-09-25

### Added

- Support loading PNG and WebP images
- Tech Gian's limited edition trial with the exclusive Yahiro mini-route
- Ability to jump back to a previous message from the history log
- Partial auto text carrying over multiple messages when there is too many lines
- Fonts can be overriden to accommodate for differences in languages
- Alternative soundtrack can be used
- Android target now includes armeabi-v7a

### Changed

- Multithreaded background asset loading
- High-resolution textures can be combined with translated or censored CGs

### Fixed

- Background music used to play longer than intended during some scene transitions
- Background image always appears after loading a save file (thank you Mizuto)
- ADV name no longer lingers unnecessarily
- ADV name can fit more characters than before
- History log is being cleared after return to title
- Startup times on Android are significantly improved
- Scroll bars are now correctly positioned and don't have issues with semi-transparency
